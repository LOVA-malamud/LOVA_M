# קטלוג נתונים

הנתונים הצמודים לתרגיל נשארו לידו כדי להקל על שימוש ולשמור על הקשרים. לא נוצרו עותקים כפולים.

| קובץ | מיקום ושימוש | מקור / פרסום |
|---|---|---|
| cluster_moons.csv, cluster_circles.csv | [DBSCAN](../04-machine-learning/date-unverified-2.9.27-dbscan/) | שתי עמודות מספריות X1/X2; מקור היצירה אינו מתועד |
| bank-full.csv | [תיקיית KMeans](../04-machine-learning/undated-23.8-kmeans-images/) | נתוני בנק ללא שמות או מזהי לקוחות בכותרות; מקור ורישיון לא אומתו; לא נמצאה הפניה בקוד |
| movie_scores.csv | [תיקיית KMeans](../04-machine-learning/undated-23.8-kmeans-images/) | מכיל שדות שמות; מקומי בלבד עד אימות מקור והרשאת שיתוף |
| Churn_Modelling.csv | `datasets/local-only/` | מכיל שמות ומזהי לקוחות; מקומי בלבד עד אימות מקור והרשאת שיתוף |
| dog_image.jpeg | [KMeans](../04-machine-learning/undated-23.8-kmeans-images/) | משמש לכימות צבעים; מקור התמונה לא תועד |
| rock_1.png, paper_1.png, scissors_1.png | [משחק Pygame](../projects/rock-paper-scissors/undated-25.2/) | נכסי משחק מקוריים במאגר; מקור חיצוני לא תועד |
| ekom_database.db | שורש המאגר, מקומי בלבד | SQLite; תוכן לא פורסם ולא שוכתב |

אין לפרסם מידע אישי או מסדים פרטיים. לפני הוספת dataset חדש יש לציין מקור, רישיון, תיאור עמודות, והתאמה לפרסום.
