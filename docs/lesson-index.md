# אינדקס שיעורים

האינדקס הפעיל עבר ל־[LESSONS_INDEX.md](../LESSONS_INDEX.md), עם חיפוש לפי תאריך ולפי נושא, מושגים, קוד, תרגילים ופערים.

ההתקדמות האישית מנוהלת ב־[LEARNING_PROGRESS.md](../LEARNING_PROGRESS.md). קיומו של קוד אינו מעיד על הבנה או עבודה עצמאית.

[מפת המעבר המקורית](migration-map.csv) נשארה ללא שינוי. צילום מיפוי השיעורים בעת הקמת המעקב נמצא ב־[lessons.json](learning/lessons.json).
