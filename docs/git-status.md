## לפני פרסום

1. לעבור על README, האינדקס ומפת המעבר ולאמת תאריכים שסומנו לא ודאיים.
2. להחליט אם יש מקור ורישיון המאפשרים שיתוף של נתונים ותמונות שמקורם טרם תועד.
3. לתקן תרגילים לא גמורים בהמשך הלמידה, בנפרד מהארגון.
4. לקבל אישור מפורש לפני push של הענף. לא בוצעו push או merge ל־main.

הסרה מהמעקב אינה מוחקת מהיסטוריית Git מידע שפורסם בעבר. לא בוצע שכתוב היסטוריה.
