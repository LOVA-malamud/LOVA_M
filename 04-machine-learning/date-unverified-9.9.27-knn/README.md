# תרגיל KNN — הכנה למבחן

הפתרון נמצא בקובץ `tirgul_00.py`.

## על איזו דוגמה בקורס הפתרון מבוסס?

קראתי את [מחברת המורה משיעור 15](https://github.com/pythonai211225-rgb/02.08.2026/blob/main/knn_02_08_2026.ipynb), את [סיכום השיעור](https://pythonai211225-rgb.github.io/python_libs/lessons/15_lesson/index.html), ואת קבצי התרגול המקומיים שלך ב־`04-machine-learning/2026-07-15-polynomial-regression` וב־`04-machine-learning/date-unverified-6.8.27-regression`.

הפתרון מתאים את דוגמת סיווג הפירות במחברת לסיווג חברי חדר הכושר. הוא משתמש ב־NumPy, ב־MinMaxScaler וב־KNeighborsClassifier, כמו דוגמת המורה. חישוב המרחקים בעזרת `np.linalg.norm` מופיע גם הוא במחברת.

## סדר העבודה שכדאי להבין

1. `np.array` יוצר מערכים עם הנתונים. `np.column_stack` מחבר את הגיל והשכר לשתי עמודות, כמו חיבור תכונות הפירות בשיעור.
2. `X` מכיל את התכונות: גיל ושכר. `y` מכיל את התשובות הידועות: `No` לחבר A ו־`Yes` לחבר B.
3. `KNeighborsClassifier` נוצר עם `k=1`, כפי שנדרש בשאלה. `model.fit(X, y)` שומר את דוגמאות האימון ואת הסיווגים שלהן.
4. `model.predict(new_member)` מסווג את החבר החדש לפי השכן הקרוב ביותר. הלולאה עם `np.linalg.norm` מציגה את המרחקים כדי להבין את הבחירה.
5. מנרמלים את שתי התכונות, מפעילים שוב `fit` עם הנתונים המנורמלים, ומסווגים את החבר החדש לאחר שעבר אותו נרמול.

## ההתאמה החשובה לשאלה

במחברת המורה כל נתוני הפירות נמצאים בטבלה, ולכן מפעילים `fit_transform(X)` כדי ללמוד את גבולות העמודות ולנרמל את הנתונים.

כאן נתונים רק שני חברים, אבל השאלה מספקת בנפרד את גבולות **כל מסד הנתונים**: גיל 20–60 ושכר 4,000–12,000. לכן `database_limits` מכיל את המינימום והמקסימום של כל עמודה. מפעילים עליו את `fit_transform` שנלמד בשיעור כדי שה־scaler ילמד את הגבולות הנתונים. אלה גבולות לנרמול בלבד; הם אינם חברים נוספים ואינם נכנסים למודל KNN.

לאחר מכן מפעילים `transform` על A ו־B ועל החבר החדש. כך כולם נמדדים לפי אותה נוסחה:

```text
age_normalized = (age - 20) / (60 - 20)
salary_normalized = (salary - 4000) / (12000 - 4000)
```

אין לבצע `fit_transform` מחדש על החבר החדש: פעולה כזאת תלמד ממנו גבולות חדשים במקום להשתמש באלה שכבר נלמדו.

## התוצאות וההסבר

| מצב | מרחק ל־A | מרחק ל־B | תחזית |
|---|---:|---:|---|
| לפני נרמול | 800.24996 | 2000.00025 | No |
| אחרי נרמול | 0.50990 | 0.25125 | Yes |

לפני הנרמול, הפרשי השכר גדולים בהרבה מהפרשי הגיל, ולכן הם שולטים במרחק. אחרי הנרמול כל הפרש נמדד ביחס לטווח העמודה שלו. הגיל של החבר החדש קרוב מאוד לגיל של B, וכעת גם המרחק הכולל ל־B קטן יותר.
